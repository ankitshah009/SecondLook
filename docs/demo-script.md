# Two-minute demo

Before presenting, run the production build, verify provider credentials, and complete one live inspection. Do not call local browser or temporary memory “Kernel” or “Neon.” Use the actual capability indicators and verified record.

**0:00–0:15 — The personal job.** “Second Look turns a subscription offer into a decision on my terms. I can spend $40 today, want monthly billing, and don’t want a year-long commitment.” Point to the guardrails.

**0:15–0:40 — The evidence.** Check the default offer. Show the captured storefront and expand the annual payment passage. “$29 per month is a correctly qualified equivalent. It still means $348 upfront—not a fit for me. The agent isn’t calling a true claim a lie.”

**0:40–1:05 — The action.** Show the monthly plan, deterministic rule checks, and observed $35 quote. Review and approve the exact demo quote. Show the saved, read-back decision receipt. “Approval is mine. This is synthetic; no real subscription or payment is created.”

**1:05–1:35 — The trust moment.** Select “Quote changes,” check again, review, and approve. The final recheck sees $45 and blocks saving against the $40 limit. “The earlier result cannot authorize a different total.”

**1:35–1:50 — Honest uncertainty.** Select “Incomplete terms” or show a prepared live run of that scenario. Expand the unresolved cancellation passage. “Missing terms stay unresolved; they don’t become facts.” If showing any prior capture instead of a live run, explicitly label it recorded.

**1:50–2:00 — The wider input.** If Exa is connected, show one actual public-offer research result with its passage, URL and retrieval time. Explain that real merchant research is read-only and exact plan applicability may remain unestablished.

## Q&A boundaries

- Real merchant checkout is not enabled. The complete actionable loop uses the labeled synthetic storefront.
- Prices and eligibility are separate. Arithmetic and preference checks run in TypeScript, not model reasoning.
- Kernel performs the browser actions when configured; Mastra + Neon Gateway extract/explain; Neon stores records; Assistant UI streams the evidence assistant; Exa gathers related source passages.
- Each quote is signed, rechecked, idempotently stored, and read back. A missing retrieval cannot prove a term or authorize an action.
- Missing credentials are an unavailable integration, not a successful demo. Screenshots are user-provided observations, not independently verified browser captures.
